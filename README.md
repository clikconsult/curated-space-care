# Pristine Spaces

Design a complete ultra-premium cleaning company website consisting of six interconnected pages:

Home

Services

About

Portfolio

Blog

Contact

The website must feel like a high-end luxury property-services, hospitality, or interior-design brand.

It must NOT look like an AI-generated website, generic cleaning template, SaaS landing page, WordPress theme, or typical local cleaning company website.

The visual quality should feel comparable to a professionally art-directed luxury hospitality or property brand.

1. BRAND POSITIONING

The company provides premium:

Residential cleaning

Commercial cleaning

Deep cleaning

Move-in / move-out cleaning

Upholstery and carpet cleaning

Specialist cleaning

Property-care services

The brand should communicate:

Precision · Trust · Discretion · Sophistication · Reliability · Attention to Detail · Exceptional Standards

The target customer should feel that this company is capable of caring for:

Luxury homes

Executive apartments

High-end residential properties

Corporate offices

Hospitality environments

Commercial properties

Premium facilities

Position cleaning as a professional property-care service, not as a commodity.

The design should communicate:

Quiet luxury. Professional precision. Exceptional results.

3. TYPOGRAPHY

Typography is one of the most important elements.

Use a premium editorial serif for major headlines.

Preferred direction:

Cormorant Garamond

Instrument Serif

DM Serif Display

Playfair Display

Libre Baskerville

Or another sophisticated high-contrast editorial serif

Pair it with a refined modern sans-serif:

Manrope

DM Sans

Inter

Neue Haas Grotesk-style typography

Helvetica Neue-style typography

Use the serif for:

Hero headlines

Section headings

Large editorial statements

Pull quotes

Major page titles

Use the sans-serif for:

Body copy

Navigation

Buttons

Metadata

Labels

Forms

Avoid:

Poppins everywhere

Roboto everywhere

Montserrat everywhere

Arial

Generic rounded SaaS fonts

Futuristic fonts

Typography should feel like a luxury hotel brochure or premium architectural magazine.

Use large editorial headlines, generous line height and carefully controlled letter spacing.

4. GLOBAL DESIGN LANGUAGE

Use:

Carefully controlled colour

Minimal cards

Avoid:

Excessive rounded cards

Excessive shadows

Excessive gradients

Glassmorphism

Floating blobs

Generic icons everywhere

Excessive badges

Fake statistics

Excessive animations

Generic AI illustrations

Do not make every section a three-column card grid.

Premium design comes from composition, typography, photography, spacing and restraint.

IMAGE DIRECTION

Photography is critical.

Use luxury editorial photography.

Images should communicate:

Beautiful interiors

Natural light

Warm textures

Architecture

Clean surfaces

Premium homes

Sophisticated offices

Hospitality-quality environments

Avoid:

Generic smiling cleaners

People pointing at cleaning products

Cheap-looking stock photography

Oversaturated images

Unrealistic AI-generated rooms

Images dominated by mops, buckets or spray bottles

The cleaning process can appear deeper within the site as evidence of professionalism.

The hero should sell the finished environment.

MICRO-INTERACTIONS

Use subtle, expensive-feeling motion.

Examples:

Slow image reveals

Fade-up typography

Elegant image zoom

Underline animation

Smooth page transitions

Before/after drag interaction

Gentle image movement

Animations should feel cinematic and restrained.

Never use:

Bouncing

Spinning

Floating blobs

Excessive parallax

Flashy transitions

Constant motion

The user should notice the design, not the animation.

RESPONSIVE DESIGN

The mobile experience must be designed intentionally.

Do not simply stack the desktop design.

On mobile:

Maintain editorial typography

Preserve whitespace

Use strong photography

Recompose asymmetrical sections

Keep CTA buttons accessible

Keep navigation minimal

Ensure forms are easy to complete

Maintain the luxury feel

The mobile website should feel like a premium mobile editorial experience.

ANTI-AI DESIGN RULE

This is extremely important.

The finished design MUST NOT look AI-generated.

Avoid common AI website patterns:

Generic hero + three cards

Excessive rounded rectangles

Purple/blue gradients

Glowing buttons

Random decorative shapes

Floating blobs

Excessive icons

Generic stock photography

Huge meaningless statistics

Every section centred

Every section using identical spacing

Excessive glassmorphism

Excessive shadows

Generic SaaS typography

Repetitive card layouts

Instead:

Art-direct the composition.

Use intentional asymmetry.

Use varied section heights.

Use large typography.

Use unexpected but tasteful image placement.

Use whitespace.

Use editorial rhythm.

Use restrained borders.

Use sophisticated typography.

Make the website feel designed, not assembled.

OVERALL CREATIVE REFERENCE

The visual language should sit somewhere between:

Luxury Hotel Website
+
High-End Interior Design Studio
+
Premium Property Management Brand
+
Fashion Editorial

The final impression should be:

"This company takes exceptional care of premium spaces."

Not:

"This is a website for a cleaning company."

The website should feel expensive because of:

Typography + Photography + Composition + Whitespace + Hierarchy + Restraint.

Not because of unnecessary visual effects.

Create all six pages as a single coherent design system, with shared navigation, typography, colour tokens, buttons, spacing, interactions and footer.

Ensure every page feels like it belongs to the same premium brand.
